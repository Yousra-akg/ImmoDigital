# ImmoDigital
ImmoDigital est une plateforme de gestion immobilière centralisée conçue pour digitaliser et sécuriser les transactions de vente et de location. Le projet vise à éliminer les confusions liées aux intermédiaires informels en instaurant un workflow rigoureux entre trois acteurs clés : l'Administrateur, qui gére les biens,  supervise l'activité et assigne les dossiers ; le Vendeur (Chargé de clientèle), qui traite les demandes et assure le suivi personnalisé ; et le Public, qui peut consulter des offres certifiées pour acheter ou louer, ou soumettre une proposition de vente de son propre bien directement à l'agence via des formulaires.
